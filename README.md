# webink-releases

**Webink** is a Flutter-based reading application designed to provide a simple and convenient way to discover, organize, and read manga from multiple external sources.

The application acts as a reader and does not host or manage the content provided by these sources.
- **Multiple Sources**: Browse content from multiple external manga sources.
- **Discover**: Explore trending titles and the latest releases available from each source.
- **Search**: Search for titles across individual sources and your personal library.
- **Library**: Save and organize your favorite titles from any available source.
- **Reading**: Read chapters directly through a clean and optimized reader.
- **Cloud Sync**: Sync your library using your Google account when signed in.
- **Cross-platform**: Built with Flutter for a consistent experience across supported platforms.
